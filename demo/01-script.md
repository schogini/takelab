# From sensor to story

A small project. A clear explanation. One great take.

Today, we are turning a handful of temperature readings into a story people can follow.

## 1. Show the idea

Open **slide.svg** on the right.

We will read the data, find the hot reading, and show the result. Keep this script here while you change references.

## 2. Run the code

Open **demo.py** to explain the program.

Switch to **Terminal** and run:

`python3 demo.py`

Our threshold is 30 degrees. One reading crosses it. Explain the result, then pause for a moment.

## 3. Make it visual

Open **dashboard.html** and choose **Browse**. Click **Show threshold** to reveal the limit. Choose **Source** to explain the HTML.

Open **handout.pdf** for the one-page summary. Try the annotation tools to highlight the main idea.

## 4. Make it yours

Open **field-notes.txt**, click **Edit**, and add a note. Save only if you want to keep the change.

Adjust the script size and scroll speed in **Prompt**. Drag the divider to make this column comfortable to read.

## 5. Try a take

Choose 16:9. Position your cameras. In **Record**, choose quality and audio, then share this TakeLab tab.

Stop, review, download. Your next take starts here.

Demo data is invented. No hardware, account, API key, internet access or extra Python packages are needed to run this project.
