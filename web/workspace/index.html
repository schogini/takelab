Paste as typing

By default, newlines become spaces. The final Enter is always yours. Typing stops when you switch tabs, restart or close the terminal, or type directly in the terminal. Use Stop typing to stop immediately. Timing varies slightly for a natural pace.

Open web address

App mode lets this app use its own cookies, storage and WebSocket origin. Automatically selected for localhost:8501 and *.streamlit.app.

Some websites block embedded viewing or require a full browser for sign-in. Use ↗ above the view to open the entered URL externally. Links followed inside a site may not update this address.

Explain on screen

Select a tool, then move or drag over the browse view. Laser fades away; pen and highlighter marks stay with this tab. Use Done or Escape to click, scroll, select text, or type. These are screen overlays; marks do not move with scrolled content. Undo also restores cleared marks. Marks reset on reload.
